Proyecto Esteganografía

Sistema para Ocultar Información dentro de Imagen con Cifrado Blowfish

Sistema informático de escritorio desarrollado en C# que permite ocultar información secreta dentro de imágenes utilizando técnicas avanzadas de esteganografía combinadas con cifrado Blowfish para máxima seguridad. La aplicación permite insertar texto, documentos o cualquier tipo de información digital dentro de archivos de imagen sin alterar visiblemente la imagen original. El sistema incluye funciones de cifrado y descifrado, gestión de claves de seguridad, interfaz gráfica intuitiva y capacidad de procesar múltiples formatos de imagen. Ideal para comunicaciones seguras, protección de información confidencial y aplicaciones de seguridad informática donde la discreción es fundamental.

Libro de Clases Digital

Plataforma para modernizar la gestión escolar en establecimientos públicos del SLEP Colchagua, reemplazando procesos físicos por trazabilidad digital, reportabilidad y operación en línea.

Problema

SLEP Colchagua gestionaba los libros de clases de forma manual y física, sin trazabilidad, respaldo digital ni visibilidad en línea para docentes y equipos directivos.

Mi aporte

Participé en el desarrollo full stack y la mantención evolutiva del sistema, agregando módulos operativos, reportabilidad, seguridad y herramientas de trazabilidad para establecimientos educacionales.

Operación escolar
  • Panel Home para directores, docentes y UTP con estadísticas, seguimiento, operaciones, actividades, tareas pendientes, eventos y notificaciones.
  • Gestión de asistencia actual por curso, eventos del día, distribución de conductas y ubicaciones de incidentes.
  • Sistema de anotaciones e incidentes de convivencia escolar con historial y respaldo documental.
Reportes y documentos
  • Generación de informes PDF y exportación Excel para reportes pedagógicos y administrativos.
  • Reporte de conducta en PDF para apoderados y uso interno.
  • Verificación de documento oficial mediante código QR y firma digital integrada con Clave Única.
Seguridad y trazabilidad
  • Gestión de usuarios con roles para docentes, directores y administradores.
  • Validaciones, guards, interceptores, sesiones seguras y control de acceso.
  • Logs de auditoría para trazabilidad de acciones relevantes del sistema.
Evolución técnica
  • Migración Angular 18 a 21, actualización de componentes, dependencias y resolución de compatibilidades.
  • Notificaciones multicanal mediante app interna, correo electrónico y WhatsApp.
  • Automatización de despliegues y soporte de operación en entorno productivo.
Stack
Angular 21 Python Flask SQLAlchemy Docker NGINX GitHub Actions Kubernetes PDF/Excel QR Clave Única
Impacto

Sistema activo en más de 10 establecimientos educacionales del SLEP Colchagua. Reemplazó el libro físico por una solución digital con respaldo automático, respaldada por la Circular N°30 del Ministerio de Educación y el Estándar REX N°3335/2020.

Trámites Online Institucional

Digitalización de más de 13 procesos administrativos gubernamentales para el SLEP Colchagua

Arquitectura, diseño, desarrollo e implementación de más de 13 procesos administrativos gubernamentales digitalizados

Problema

Más de 13 procesos administrativos del SLEP Colchagua se gestionaban de forma manual, por correo o presencialmente, sin trazabilidad, respaldo estructurado ni control de tiempos de respuesta.

Mi aporte
  • Diseñó la arquitectura e implementó 13+ trámites digitales: renuncias, permisos, anotaciones de mérito/demérito, certificados, denuncias Ley Karin, traslados, entre otros
  • Desarrollé el sistema completo de evaluación funcionaria (1° y 2° evaluación, precalificación, junta calificadora) con validación por Clave Única
  • Automaticé flujos de aprobación jerárquica con notificaciones y trazabilidad documental
  • Generación de reportes consolidados y respaldo automático por cada trámite
Stack
Python Flask SQLAlchemy SIMPLE PHP
Impacto

Reducción significativa de horas-hombre en trámites manuales. El sistema de evaluación funcionaria fue destacado por la Dirección de Educación Pública (DEP) como aporte relevante en modernización, reduciendo procesos de semanas a días por etapa con respaldo automático y datos unificados.

Problema

Stack
C# Python MySQL SQL Server

Sistema Automatizado de Etiquetado Industrial

Gestión e impresión automatizada de etiquetas para productos de exportación

Problema

El proceso de solicitud y emisión de etiquetas era manual y propenso a errores, generando desfases de información, etiquetado incorrecto y pérdida significativa de material en la línea de producción de exportación.

Mi aporte
  • Botonera física con botón de contacto y switch automático integrada a PLCs de control para activar el flujo de impresión
  • Raspberry Pi como controlador central que consulta en tiempo real datos de producción, lotes, códigos de barras e información de etiqueta desde una base de datos centralizada
  • Sincronización de datos mediante red local con impresoras térmicas industriales
  • Eliminación de desfases de información y reducción drástica de errores de etiquetado
Stack
Raspberry Pi PLCs Base de Datos Centralizada Red LAN Industrial Impresión Térmica
Impacto

La automatización optimizó los tiempos de solicitud y emisión, eliminando desfases de información y generando un ahorro de hasta $30.000.000 de pesos en pérdida de material por errores de etiquetado.
